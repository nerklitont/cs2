# CS2 UPGRADE

Сайт по игре CS2 с режимом **Upgrade** — апгрейд скинов с колесом удачи.

## Функционал

- **Upgrade** — выбираете скин из инвентаря, выбираете желаемый скин, крутите колесо. Шансы зависят от разницы цен скинов.
- **Настройка шансов** — слайдер для настройки процента шанса и множителя.
- **Маркет** — покупка скинов за внутренний баланс с фильтрами и поиском.
- **Инвентарь** — управление предметами, продажа и вывод.
- **Лента апгрейдов** — real-time обновления через WebSocket.
- **Топ апгрейд** — лучший апгрейд отображается на главной.
- **Онлайн** — количество пользователей на сайте в реальном времени.
- **Профиль** — баланс, инвентарь, история апгрейдов, пополнение.
- **Админ-панель** — управление пользователями, статистика, история, заявки на вывод.

## Технологии

- **Backend:** Node.js, Express, SQLite (better-sqlite3), Socket.IO, JWT
- **Frontend:** React 18, Vite, Framer Motion, Socket.IO Client
- **Данные:** Реальные скины CS2 с изображениями из Steam CDN

## Запуск

```bash
# Установка зависимостей
npm run install:all

# Запуск (dev)
npm run dev

# Backend: http://localhost:3001
# Frontend: http://localhost:3000
```

## Аккаунт администратора

```
Логин: admin
Пароль: admin123
```

При первом запуске создаётся аккаунт администратора и база скинов.
